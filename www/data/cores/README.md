# Bundled emulator cores

This folder holds the emulator cores (RetroArch / libretro cores compiled to
WebAssembly by the EmulatorJS project). They are part of the application, exactly
like the cores that ship with RetroArch or RetroPie — **nothing is downloaded
while the app runs**.

    npm run cores          # fetch the full set once (needs internet, ~92 MB)
    npm run cores:check    # verify the set without touching the network

`npm run dist` refuses to build an installer while a core is missing, so every
release is guaranteed to work offline. The `*.data` files are not committed to
git (size); `manifest.json` is generated by the script and lists what is bundled.
